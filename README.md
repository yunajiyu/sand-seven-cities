# 출석부에 없는 구역

한빛학원 2학년 7반 괴담 조사 기록 — 현대 한국 고등학교(한빛학원)를 배경으로 한 조사 호러 텍스트 탐험 게임입니다. HTML 파일 하나(`hanbit.html`)로 동작하며 서버가 필요 없습니다.

## 플레이 방법
1. `hanbit.html`을 브라우저로 엽니다(더블클릭 또는 창으로 끌어다 놓기).
2. 첫 화면의 **AI 설정**에서 API 키(Anthropic 또는 Gemini 등)를 입력합니다. 키가 없으면 간단한 기본 서술로 진행됩니다.
3. **전학 오기**로 새 게임을 시작합니다(만 17세 고등학교 2학년 전학생 · 기본 이름 도현). 이어 하려면 **기숙사로 돌아가기**.
4. 저장은 브라우저에 됩니다(`hanbit_save_v1`). 다른 곳으로 옮기려면 게임의 저장 내보내기/불러오기를 쓰세요.

## 상태값
체력 · **공포**(높을수록 위험, 아지트에서 회복) · **배터리**(휴대폰 %) · 손전등 · 캐시 · **벌점**(점호 누락·무단 외출, 10점 이상이면 외출 금지 경고) · **출입 권한**(1~3등급) · **시간대**(낮 → 방과 후 → 야간 → 새벽) · 교표 조각 n/8 · 유민 호감도(Lv).

## 프롬프트
- `system_prompt_hanbit.md` — 서술·유민 대사용 메인 프롬프트와 구역 즉석 생성용 보조 프롬프트의 원문(설계 초안).
- 코드에는 `SYS_BASE`(메인), `SYS_ZONE`(보조), `TURN_SCHEMA`(JSON 출력 형식)로 들어 있습니다. 상태 블록은 JSON의 `effects`로 받습니다: `체력`·`공포`·`배터리`·`손전등`·`캐시`·`벌점`·`출입권한`·`유민호감`·`교표조각`·`사전추가`·`조사보드`·`떡밥장부`.

## 아지트 꾸미기 (이미지 없음)
이미지 파일은 쓰지 않습니다. 아지트 장면은 CSS 배경(집 단계 1~4)과 이모지만으로 그립니다.
- 시설: 지으면 `FAC_SLOTS`의 자리에 이모지로 나타납니다 (티 코너 🍵, 사물함 🗄, 자전거 보관대 🚲, 작업대 🔨, 충전 거치대 🔋, 휴게 소파 🛋, 교표 연구실 🔍).
- 가구·장식·유실물 진열대: `DECOR`의 이모지(`ic`)로 표시되고 끌어서 옮깁니다.
- 단계 배경 소품: `HOME_BG`(창문·문·조명·액자·시계 등)가 단계에 따라 늘어납니다.
- 좌표·크기(%)는 `FAC_SLOTS`/`DECOR`에서 조절하며, 🛠 시설 위치 편집 모드로 끌어서 맞춘 뒤 좌표를 복사해 반영할 수 있습니다.

## 인물·관계 설정
- 플레이어와 유민은 모두 고등학교 2학년(만 17세)입니다. 인연 단계는 우정으로만 진행됩니다(낯선 사이 → 아는 사이 → 친구 → 믿는 사이 → 단짝 → 둘도 없는 친구 → 평생 친구). 연애·결혼 요소는 없고, 프롬프트에도 연애·성적 묘사 금지 규칙이 들어 있습니다.

## 학교 일과 · 수업과 땡땡이
- 낮은 9칸의 학교 일과입니다: 조례 → 1교시 → 쉬는 시간 → 2교시 → 점심시간 → 3교시 → 쉬는 시간 → 4교시 → 종례. 행동 한 번이 한 칸이고, 종례가 끝나면 방과 후입니다. 칸이 바뀔 때마다 🔔 알림이 뜨고 지금 칸에 맞는 버튼이 나옵니다.
- 조례·수업·종례는 교실에서, 점심시간은 버튼을 누르면 급식실로 이동해 무료 급식을 먹습니다(소문을 들을 수 있음).
- 전학 첫날(1일째) 조례에서 「전학 인사하기」로 담임의 소개, 자기소개, 옆자리 유민과의 첫 만남이 이어집니다.
- 📚 수업 듣기: 한 교시는 행동 3번(`CLASS_ACTIONS`)이고, 수업 듣기 버튼뿐 아니라 수업 중 고른 선택지·입력 행동도 한 번으로 셉니다. 마지막 행동 뒤에 종이 울리고 "🔔 1교시 수업이 끝났습니다 → 쉬는 시간" 알림이 뜹니다. 교시마다 30% 확률로 마지막 장면에서 단서(조사 보드, 가끔 교표 조각 위치)를 얻고 성장 경험치 +1. 수업 도중 빠져나가면 땡땡이로 처리됩니다. 시간표는 날짜로 정해지고, 과목마다 단서의 성격이 다름(국어 기록·문서, 수학 숫자·좌표, 영어 구역 이름의 유래, 과학 구역 환경, 한국사 연혁, 사회 지도·위치, 음악 소리·방송, 체육 이론 안전 수칙, 기술·가정 건물 구조). 수업 칸에 수업을 듣지 않고 시간이 흐르는 다른 행동(둘러보기·거닐기·급식 등)을 하면 땡땡이로 처리되어 확률로 적발됩니다(칸당 한 번, 학교 밖이면 결석 기록만).
- 🏃 땡땡이치기: 들킬 확률 35%(그날 땡땡이마다 +10%, 벌점 10점 이상이면 +15%). 안 들키면 공포 −1과 25% 확률의 단서, 들키면 벌점 +2.
- 상수는 `SCHOOL`, `CLASS_CLUE_P`, `SKIP_CATCH_P` 등으로 코드 위쪽에 모여 있어 조절할 수 있습니다.

## 장소 이동 인식
- 서술 AI가 응답에 `위치`(장면이 끝났을 때 플레이어가 있는 곳)를 담고, 선택지에는 목적지 `to`를 담습니다. 코드는 그 값을 지점 또는 임시 장소로 반영합니다. "자리를 옮겨", "~로 향했다" 같은 약한 표현도 처리됩니다.
- 직접 입력 문장의 정규식 해석은 보조(확인 칩·즉시 이동)로 남아 있습니다.
- 수업 칸에 교실을 벗어나면 땡땡이로 처리됩니다(그 칸이 지나가고 확률로 적발, 벌점 +2).

## 학교 안 구조
- 지점은 교실·복도·매점·급식실·교무실(학교 안), 기숙사·정문·상점가·저수지 둑길(학교 밖) 아홉 곳입니다. "복도로 나간다" 같은 문장이나 🏫 학교 지도(눌러서 이동)로 옮길 수 있습니다.
- 글에 장소가 여럿 나오면 가장 나중에 나온 곳을 목적지로 봅니다("교실에서 복도로 나간다" → 복도).
- 칸이 끝나면 서술 뒤에 "🔔 1교시 수업이 끝났습니다 → 쉬는 시간" 알림이 뜹니다. 전학 첫날 조례에는 담임의 전학생 소개 지문이 먼저 나옵니다.

## 서술과 일과 맞추기
- 시간의 기준은 게임이지만, AI가 서술에서 수업 끝 종소리를 울리면(응답의 `칸종료`가 true이거나 "~종료를 알리는 종소리" 같은 문장이 있으면) 게임도 수업을 끝내고 다음 칸(쉬는 시간 등)으로 넘깁니다. 수업 시작 종소리는 끝으로 보지 않습니다.
- 프롬프트에는 수업 중 [수업 끝] 지시가 있을 때만 종을 울리라고 되어 있습니다.

## 학교 층 구조
- 1층(복도·교무실·보건실·매점·급식실·도서관) · 2층(교실·음악실·가사실·과학실·복도) · 3층(방송실·미술실·자습실·컴퓨터실·복도) · 옥상 · 학교 밖(정문·기숙사·운동장·체육관·상점가·저수지 둑길). 하단 장소 버튼과 🏫 학교 지도가 층 탭으로 나뉩니다.
- "복도로 나간다"는 지금 층의 복도로 이동하고, "2층 음악실로 간다"처럼 층과 방을 함께 써도 됩니다. 지점은 `PLACES`에서 한 곳에 정의되어 있어 방을 더하기 쉽습니다.
- 특별실(도서관·음악실·가사실·과학실·방송실·미술실·자습실·컴퓨터실·옥상·운동장·체육관)은 🔎 둘러보기로 단서를 찾을 수 있고(하루 3번까지), 보건실은 하루 한 번 쉴 수 있습니다.

## 직접 행동 판정 고르기
- 직접 입력창 위의 🎲 판정 칸에서 능력치(체력·지혜·매력·생존술)를 골라 행동하면 그 능력치로 바로 2d6 판정합니다.
- 난이도(쉬움 7 · 보통 9 · 어려움 11)는 항상 무작위입니다. 판정 **전에** "🎯 이번 판정은 보통 난이도입니다"와 성공 확률이 먼저 표시되고(능력치를 바꿔도 난이도는 그대로), 판정하면 새로 정해집니다.
- 장면이 위험할수록 어려움이 더 자주 나옵니다(`DC_WEIGHTS`, 위험도 0: 쉬움 40·보통 40·어려움 20% → 위험도 3·전투: 12·33·55%). 구역의 방 위험도, 전투, 한빛시 뒷길·임시 쉼터(1)가 기준입니다.
- 직접 행동뿐 아니라 AI 선택지의 판정과 판정 확인 칩도 같은 방식입니다. 구역의 심장 열기처럼 이야기상 고정된 판정은 그대로입니다.
- "판정 없이 진행"은 판정·확인 칩 없이 이야기로만 진행하고, "자동"(기본)은 기존처럼 필요할 때만 판정을 제안합니다.

## 모바일 선택지
- 화면 폭 760px 이하에서는 선택지가 한 줄이 되어 2개씩 보이고, 나머지는 옆으로 밀어서 고릅니다(`.cslide`, 다음 칸이 살짝 보임). 넓은 화면에서는 이전 배치 그대로입니다.
- 일과 안내 줄(🔔 지금 …)은 버튼 줄 아래 이름표로 옮겨 모바일에서 버튼이 찌그러지지 않게 했습니다. AI 선택지의 판정 배지는 "🎲 능력치 · 난이도 무작위"로 표시됩니다.

## 점호 시간까지 기다리기
- 종례가 끝난 방과 후에 캠퍼스에서 🔔 점호 시간까지 기다리기 버튼(또는 "점호 시간까지 기다린다" 입력)을 누르면 야간이 될 때까지 시간을 보내고 기숙사 점호 장면으로 넘어갑니다. 낮(수업 중)에는 쓸 수 없습니다.

## 소등 후 외출과 기숙사 휴게
- 야간·새벽(소등 후)에 기숙사 밖으로 나가면 그날 밤 처음 한 번 40% 확률(벌점 10점 이상이면 +15%)로 들켜 기숙사로 돌려보내지고 벌점 +2입니다. 들키지 않으면 그날 밤은 자유롭게 다닐 수 있습니다(`CURFEW_*` 상수, AI가 알려 준 `위치`도 같은 규칙).
- 기숙사에서는 🍵 휴게실 차 마시기(공포 −1, 하루 3번)와 🚿 따뜻한 샤워(공포 −2, 하루 1번)로 공포를 낮출 수 있습니다.
