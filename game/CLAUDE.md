# 모래 아래의 일곱 도시 — 픽셀 RPG 작업 지시서

이 파일은 Claude Code가 이 프로젝트를 이어받아 작업할 때 읽는 지시서입니다.
사용자는 이 게임을 **혼자 만들고 혼자 플레이**합니다. 공유·배포 목적이 아닙니다.

## 0. 사용자와 일하는 방식

- 사용자에게는 항상 **존댓말**로 답합니다.
- 답변 끝에는 이어서 할 수 있는 작업을 2~3개 제안합니다.
- 사용자는 UI/UX 디자이너이고 개발자는 아닙니다. 명령어나 개념이 나오면 한 줄로 쉽게 풀어 설명합니다.
- 되돌리기 어려운 결정(엔진 교체, 폴더 구조 대개편, 스토리 변경)은 먼저 묻고 진행합니다.
- 사용자가 직접 플레이할 게임이므로, 작업 보고나 디버그 화면에 엔딩·보물의 진실 같은 스포일러를 굳이 띄우지 않습니다.

## 1. 지금까지 정해진 것

### 게임 개요
- 원래 AI가 서술하던 단일 HTML 텍스트게임을, **고정 스토리 탑다운 픽셀 RPG**로 다시 만듭니다.
- 스토리 설정집(Claude Docs): https://claude.ai/code/artifact/32cdb61d-e963-4286-b79c-4867178a6c51
  - 열 수 없으면 사용자에게 내용을 붙여 달라고 요청합니다. 아래 요약만으로도 1단계 작업은 가능합니다.

### 스토리 요약 (설정집 2안 기준)
- 무대: 큰 강 아스라가 흐르는 계곡 '아스라 범람원'. 천 년 전 '큰물의 밤'에 일곱 도시가 호수 아래로 가라앉았고, 올해 백 년 만에 물이 크게 빠져 폐허가 드러남.
- 목표: 별지도 조각 8개 모으기. 일곱 도시에 하나씩, 여덟 번째는 적 대장 칼리드가 가짐.
- 주인공 도현(하일 마을의 지도 수선공, '별 읽는 자'). 동행 NPC 유민(24세 떠돌이 음유시인, 노래로 바람과 물을 부림, 호감도 3단계).
- 적: 철인장 원정대(칼리드, 사라샤, 무르타, 병사 3종). 모두 사람.
- 구조: 프롤로그(하일) → 1막 이람 → 2막 별지도의 ??? → 3막 여섯 도시 + 곁가지(자이툰, 카스르) → 4막 칼리드·최종 던전 → 에필로그.
- 이름(하일, 이람, 유민 등)은 중동풍 그대로 유지. 화면은 유럽 시골풍이므로 분위기는 이름·대사·효과음(중동 음계)으로 살림.

### 기술 결정
- 엔진: **Phaser** (Phaser 3 계열 최신 안정판. 설치 시점에 Phaser 4가 정식 출시되어 있으면 사용자에게 어느 쪽으로 할지 묻기)
- 맵 제작: **Tiled** (에셋에 Tiled 파일과 충돌 정보가 포함되어 있음)
- 전투: 별도 전투 화면 없는 **필드 액션 전투** (에셋의 베기 동작 활용)
- 생존 요소: 물 게이지 대신 **등불 기름** 게이지
- NPC·적: 기본 주인공 스프라이트를 **코드에서 색 치환**해서 만듦
- 도현·유민 스프라이트: 사용자가 **따로 제작해서 추가 예정**. 그전까지는 기본 주인공 + 색 치환으로 임시 사용
- 효과음: Web Audio API로 직접 합성
- 실행 방식: 개발 중에는 **로컬 서버**, 플레이용 최종본은 **HTML 한 파일로 묶어** 더블클릭으로 열기
- GitHub·Netlify 등 배포는 하지 않음

## 2. 에셋: The Fan-tasy Tileset (Free) 1.5.9

사용자가 zip으로 제공합니다(`The_Fan-tasy_Tileset_Free_1.5.9.zip`). `assets/fantasy-tileset/`에 풀어 둡니다.

확인된 내용:
- 타일 크기 16×16px
- 지면(풀·흙), 흙길, 움직이는 강·연못(가장자리 모래톱), 바위 절벽·돌계단
- 초가 돌집 4채, 우물, 돌 아치문, 소품 18종, 바위 5종, 나무 4종, 덤불 7종, 움직이는 꽃·모닥불·문
- 캐릭터: 주인공 1명 (`Character_Walk.png` 160×192, `Character_Idle.png`, `Character_Slash.png` 240×192)
  - 한 프레임 약 40×48px로 보임 (걷기 4열×4행, 베기 6열×4행). **행 순서(방향)는 직접 열어 확인**할 것
- 샘플 맵: `Tiled/Tilemaps/Beginning Fields.tmx` (+ 미리보기 png) → 하일 마을로 사용
- 없는 것: 사막, 실내·지하 던전, 성벽, NPC·적·몬스터, UI

주의할 점:
- Phaser는 `.tmx`가 아니라 **Tiled JSON**을 읽습니다. Tiled에서 JSON으로 내보내되, 외부 타일셋(`.tsx`)은 **맵 안에 포함(embed)** 해서 내보내야 합니다.
- `Objects_*.tsx`는 이미지 모음(image collection) 타일셋일 수 있습니다. Phaser의 타일 레이어로 바로 안 그려질 수 있으니, 오브젝트 레이어를 읽어 스프라이트로 배치하거나 아틀라스(`Atlas_*.tsx`) 쪽을 쓰는 방법을 확인해서 고릅니다.
- `.tsx` 안의 충돌 정보를 Phaser 충돌로 옮기는 방법을 정합니다.
- 무료판 사용 조건은 아직 확인하지 않았습니다. 동봉 PDF(`The Fan-tasy Tileset Documentation.pdf`)에서 수정·재배포 관련 조건을 확인해 사용자에게 알려 줍니다.

## 3. 폴더 구조 (제안)

```
project/
├─ CLAUDE.md
├─ package.json
├─ index.html
├─ src/
│  ├─ main.js            # Phaser 설정 (pixelArt: true, 정수 배율)
│  ├─ scenes/            # Boot, Preload, Town(하일) ...
│  ├─ systems/           # 대화, 플래그, 색 치환, 낮밤 ...
│  └─ data/
│     ├─ dialogue/       # 대사 데이터 (JSON)
│     ├─ flags.json      # 이벤트 플래그 정의
│     └─ palettes.json   # 색 치환표
├─ assets/
│  ├─ fantasy-tileset/   # 원본 에셋 (수정하지 않음)
│  ├─ maps/              # Tiled 원본(.tmx)과 내보낸 JSON
│  ├─ characters/        # 도현·유민 스프라이트 (사용자 제공 예정)
│  └─ fonts/
├─ scripts/
│  └─ build-single.*     # 한 파일 묶기 스크립트
└─ dist/
   └─ game.html          # 더블클릭으로 여는 최종본
```

## 4. 실행과 묶기

### 개발용 로컬 서버
- `npm run dev` 한 줄로 서버가 켜지고 브라우저에서 `http://localhost:…`로 열리게 합니다. Vite 같은 도구를 추천합니다.
- 사용자에게 서버를 켜고 끄는 법을 한 번 쉽게 설명해 줍니다.

### 한 파일 묶기
- `npm run build:single` → `dist/game.html` 하나가 생기게 합니다.
- 조건:
  - 이 파일만 더블클릭(`file://`)해서 열어도 **인터넷 없이** 실행됨
  - Phaser 라이브러리, 코드, 이미지, 맵 JSON, 대사 데이터, 폰트까지 전부 파일 안에 포함
  - 이미지는 data URI(base64)로 넣고, 맵·대사 JSON은 코드 안에 직접 넣어 Phaser 로더가 외부 파일을 읽지 않게 함
- 방법은 자유입니다(예: Vite + 단일 파일 플러그인, 또는 직접 만든 묶기 스크립트). 단 **실제로 `file://`로 열어서 동작을 확인**하고 끝냅니다.

### API 키
- 잡담 NPC용 AI 대사는 선택 기능입니다. 넣게 되면 API 키를 **코드나 파일에 직접 넣지 않고**, 게임 안 설정 화면에서 입력받아 브라우저 저장소에 보관합니다.

## 5. 작업 순서

### 1단계: 하일 마을 시험판 (가장 먼저)
목표는 "이 에셋과 이 방식으로 실제로 굴러가는지" 확인하는 것입니다.

완료 조건:
- [ ] 프로젝트 세팅, `npm run dev`로 실행
- [ ] `Beginning Fields` 맵이 화면에 정상 표시 (타일 레이어 + 건물·소품 오브젝트)
- [ ] 픽셀이 뭉개지지 않음 (pixelArt, 정수 배율)
- [ ] 임시 주인공이 4방향으로 걷고, 걷기·대기 애니메이션이 방향에 맞게 재생
- [ ] 집·바위·물·절벽에 부딪힘
- [ ] 카메라가 주인공을 따라가고 맵 밖을 보여 주지 않음
- [ ] 색 치환으로 만든 NPC 3명 배치 (예: 하미드, 주민 2명)
- [ ] NPC 앞에서 키를 누르면 한국어 대사창이 뜨고, 넘기면 닫힘
- [ ] 대화 한 번으로 플래그 하나가 켜지고, 두 번째 대화 내용이 달라짐
- [ ] `npm run build:single` → `dist/game.html` 더블클릭으로 오프라인 실행 확인

한국어 폰트: 픽셀풍 한글 폰트(예: Galmuri, OFL 라이선스)를 추천합니다. 라이선스를 확인하고 사용자에게 알려 줍니다.

### 색 치환 방식
- 기본 주인공 스프라이트에서 쓰인 색 목록을 뽑아 `palettes.json`의 기준 팔레트로 만듭니다.
- 인물마다 `{ 원래색: 바꿀색 }` 표를 두고, 로딩 시 캔버스에서 색을 바꿔 새 텍스처로 등록합니다.
- 머리·피부·상의·하의·신발 정도로 묶어서, 사람이 표를 손으로 고치기 쉽게 합니다.

### 2단계 이후 (1단계 완료 후 사용자와 확인하고 진행)
1. 대화·이벤트 플래그 시스템 정리, 도감(사전) 탭
2. 낮밤 화면 덮개, 등불 기름 게이지
3. 필드 액션 전투 (베기, 별 표식, 철인장 병사 3종)
4. 유민 동행 (따라다니기, 노래 범위 효과, 호감도)
5. 1막 이람 맵과 달빛 규칙
6. 효과음 (Web Audio 합성)
7. 나머지 도시와 곁가지, 엔딩

## 6. 사용자가 나중에 줄 것
- 도현·유민 스프라이트 시트 (기본 주인공과 같은 프레임 크기·배열로 맞추는 것을 권장)
- 1막 대사 원고
- 추가 에셋이 생기면 그때 알려 줌
